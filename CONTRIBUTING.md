# Contributing to FabricTrace Spec

We welcome architectural feedback, edge-case evaluations, and RFC revisions from systems engineers, infrastructure architects, and kernel developers.

## Submitting RFC Updates
1. Fork the repository and create your branch from `main`.
2. Make your modifications to existing RFCs or propose a new RFC file under the `RFCs/` directory.
3. Ensure your arguments are grounded in hardware realities (e.g., PCIe, NVLink, RDMA, or runtime mechanics).
4. Open a Pull Request detailing the technical trade-offs of your proposal.
